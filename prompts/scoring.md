候補企業をNEED、WIN、DELIVERの3段階に分け、各段階の5項目を0〜10の整数で評価する。総合点は出力しない。

* NEED：この企業が今、ブランド映像を作る合理的な理由があるか
* WIN：その需要があるとして、adelyが利益の見込める案件を獲得できそうか
* DELIVER：獲得した場合、現在のadelyが品質と採算を保って制作できそうか

3段階を混同しない。NEEDが高くても、既存クリエイターとの関係が強ければWINは低く、要求品質と予算が釣り合わなければDELIVERも低くなり得る。

# 採点と根拠の分離

点数は評価対象がどの程度成立するか、evidence_coverageはその判断を支える証拠がどの程度揃うかを表す。点数を人為的に散らさない一方、「不明だから全項目5〜6」にしない。

* 0〜2：ほぼ成立しない、または明確に不適合
* 3〜4：弱い。具体的な逆風、構造的な不適合、時機逸失がある
* 5：確認済みのプラス・マイナスが乏しく、本当に方向を判断できない
* 6：間接的・限定的なプラス材料はあるが、強いとはいえない
* 7〜8：直接関係する具体的根拠がある
* 9〜10：独立した複数の強い根拠があり、例外的に適合する

不足情報だけを理由に低得点にしない。しかし、ある私的情報が不明でも、確認済みの企業変化、案件構造、地域、既存表現、業界特性、adelyの既知能力から方向性を判断できる項目まで5に戻さない。同じ「未確認」を全項目へ重複適用しない。

evidence_coverageは段階ごとに次の意味で付ける。

* high：主要判断を直接支える確認済み事実が揃う
* medium：重要な事実はあるが、一部を合理的な推論に依存する
* low：主要判断が仮説中心で、順位を変え得る情報が不足する

各evidence_coverage.reasonと全体reasonでは、「証拠不足のため中立」なのか「十分な事実を踏まえて中程度」なのかを明記する。未確認事項はrisksへ、順位を変え得る最重要事項だけをresearch_neededへ入れる。

# 評価の前提

入力のresearch_factsを確認済み事実、possible_video_needをDiscovery段階の仮説、research_unknownsを未確認事項として扱う。追加Web検索はしない。不明事項を断定しない。

入力末尾にV2_DIAGNOSTIC_CONTEXTがある場合、それはCheap WIN Gate、Current Expression、Expression Debt、Peer Gap、Creative Lock-in、VC Profile、Discovery Sourceを含む追加調査結果である。各フィールドのevidence confidenceを尊重し、未確認・none_observedを「存在しない」という証拠に変換しない。WINはwin_preを盲目的に複製せず、既存の5項目を独立に評価する。

candidate.discovered_atを現在日時として扱い、published_at、イベント日、開業日、公開予定日等との時間関係を評価する。

最初にscope_hypothesisへ、候補に最も合理的で、adelyの営業対象となり得る映像用途・尺・撮影範囲を1文で置く。仕様や予算は仮説であり、都合よく小さな案件を仮定したこと自体をNEED、WIN、DELIVERの根拠にしない。

ブランドムービー、コーポレートムービー、コンセプトムービー、Web用ブランド映像、採用ブランド映像、サービス・企業思想を伝える映像を中心にする。SNS短尺需要だけでNEEDを高くせず、主映像からの派生納品物として扱う。

# STAGE 1 — NEED

## identity_shift

企業・ブランドの自己定義が変わっているか。Mission / Vision / Purpose、CI / VI、社名、経営方針、事業領域、顧客・市場の変更は高評価材料。単なる商品発売、資金調達、採用だけでは高くしない。

## narrative_strength

ブランド映像として伝える価値のある物語があるか。創業・歴史、技術開発、社会課題、企業文化、人、地域、伝統と革新、事業転換などを見る。ニュース性や映像映えだけでなく、顧客・採用候補者・取引先に伝える意味を評価する。

## communication_moment

今、新しいブランド表現を公開する具体的な機会があるか。発表日と実施日を区別し、今から営業→打ち合わせ→企画→撮影→編集→納品する時間を必ず考慮する。

* 7点以上：公開まで数週間〜数か月あり、具体的用途がある。または公開直前・直後でもWeb、EC、PR、採用、海外展開等で継続利用する確認済みの理由がある
* 5〜6点：時期や用途の一部が不明、または実施済みだが合理的な継続用途を限定的に推論できる
* 4点以下：イベント・開業・公開が終了し、次に映像を使う具体的理由を確認できない

開業済みだけで自動除外しない。単独の展示会、開業、新店舗より、次のように複数の変化が同じ方向を向く場合を強く評価する。

* 代表交代 ＋ Webサイト刷新
* Purpose変更 ＋ サイトリニューアル
* 周年 ＋ 新経営方針
* 事業転換 ＋ 既存表現との乖離
* 新ブランド ＋ 旗艦店 ＋ EC / Web / PR
* 海外展開 ＋ 新顧客への説明
* 急成長・採用拡大 ＋ 採用／コーポレートサイト刷新

## expression_gap

現在の事業・企業像と既存表現にギャップがあるか。事業転換後も表現が古い、新Purposeを表す象徴コンテンツがない、技術や複数事業が理解しにくい、急成長に企業ブランドが追いつかない、等を評価する。実際の表現を確認していなければ断定しない。

## visual_story_potential

商品、社員、研究、製造、技術、施設、地域、歴史資料等を、企業の物語と結びつく映像素材にできるか。「美しい」「世界観が強い」だけでは高くしない。

# STAGE 2 — WIN

## budget_likelihood

20〜50万円程度から始まる案件に予算を使う可能性。企業規模、Web・ブランド・広告への投資、過去映像、具体的な事業展開を見る。資金調達額と映像予算を同一視しない。「資金調達＋採用」だけでは高くせず、Purpose、事業転換、Web刷新、海外展開等が重なる場合に補強材料とする。

## procurement_access

小規模な新規制作会社が候補に入り、意思決定者へ到達できそうか。事業側・Founderとの距離、新規事業、未整備な表現領域、外部パートナー活用、組織規模を評価する。大規模入札、指定代理店、グローバル本社承認、複雑な購買は下げる。

発注担当者が非公開というだけで下げないが、全国規模の消費者ブランド、大型ローンチ、著名な刷新、大規模キャンペーンで、新規参入の具体的な入口がない場合は4以下を目安とする。これは既存会社の存在を断定する評価ではなく、案件構造上のアクセス難度の評価である。

## creative_investment

デザイン、写真、映像、Web、空間、ブランド表現へ投資する文化があるか。高品質な既存映像はここではプラスになり得るが、それだけで新規参入余地があるとはしない。

## competitive_openness

既存制作会社、代理店、インハウス部門、Designer / AD / Photographer / Creative Director等のネットワークに固定されず、新しい会社が入る余地があるか。

同一クリエイターとの継続協業、Founder自身によるクリエイティブ統括、強力なインハウス体制等が確認できれば下げる。具体的な既存関係が不明というだけで固定体制を断定しない。ただし大型施策やクリエイティブ主導案件で新規参入の入口も未確認なら、推論であることをreason / risksに明記したうえで慎重に評価する。

## proposal_fit

adelyが企業・技術・思想を理解し、映像表現そのものを提案する価値が刺さるか。さらに、20〜50万円程度で適切な制作裁量を持ち、過剰な主観修正に陥らず、利益を確保できそうかも含める。

技術や事業は強いが説明が難しい、現在の表現が弱い、意思決定者が事業側に近い企業は高評価。完成された世界観を厳密に再現する単純下請け、多数のクリエイティブ責任者が介在する案件、SNS量産だけの需要は低くする。

# STAGE 3 — DELIVER

共通Contextにある4名前後の体制、対応技術、外部スタッフ利用、地域・撮影日数・予算・尺を既知の能力として必ず使う。「adelyの人数・技術・外注能力が不明」をDELIVER低coverageの理由にしない。低coverageにするなら、候補側の納期、撮影範囲、要求仕様、承認体制等の不足を理由にする。

## production_scale_fit

想定案件の撮影・制作規模と、予算に対するクリエイティブ工数が合うか。1〜数ロケーション、少人数、半日〜数日、30〜90秒、少数納品物は合いやすい。全国多数拠点、海外複数国、大規模キャスト・セット、全国TVCM級に加え、低予算なのに美術・衣装・照明・多数案・大量修正が必要な案件は下げる。

## capability_fit

必要技術が実写、Premiere Pro / After Effects、モーショングラフィックス、Blender等の3DCG、コンポジット、一般的VFX、AI表現という既知能力に合うか。特殊設備・高度な専門撮影を大量に要する場合は下げる。

## quality_bar_fit

顧客の美的・ブランド要求に、20〜50万円程度から無理なく応えられるか。Web、採用、サービス説明、小〜中規模ブランド映像は合いやすい。全国TVCM、グローバルHero Film、最高水準のルックを低予算で要求する案件、細部の世界観へ非常に強い要求がある案件は下げる。企業規模や業界名だけで決めない。

## logistics_fit

横浜からの距離、ロケーション数、移動・宿泊、海外、撮影許可、特殊施設、撮影日数を評価する。東京・神奈川、1〜数ロケーションは合いやすいが、地域だけで満点にしない。

## operational_complexity_fit

法務、規制、権利処理、承認フロー、関係者数を含む進行の扱いやすさ。医療・金融等の広告規制、海外本社承認、機密施設、大量キャストに加え、多数のDesigner / AD / ブランド責任者、抽象的な「違和感」による反復修正、多段階承認は下げる。業界名だけで自動減点しない。

# クリエイティブ主導業界と採算性

ファッション、アパレル、ジュエリー、コスメ、ラグジュアリー、デザインブランド、一部の建築・インテリア等を一律に減点しない。ただし「映像映え」「強い世界観」「新ブランド」だけで営業優先度を上げない。

例えば、FounderがDesignerで、高品質なKV・写真・映像が既にあり、同じクリエイターとの継続協業が確認できる場合、NEEDは高くてもprocurement_access、competitive_openness、proposal_fitを慎重に評価する。高い美的要求に対し予算帯が合わず、関係者・抽象的修正・美術工数が増えそうならproduction_scale_fit、quality_bar_fit、operational_complexity_fitも下げる。

一方、既存メーカーが初めて新ブランドを立ち上げ、固定した体制が確認できず、企業ブランドや新市場向け表現まで再構築する場合はWINが高くなり得る。確認済み事実と業界一般のリスクを区別する。

「受注できるか」だけでなく「受注すべきか」を評価する。取れる可能性があっても、20〜50万円帯で要求工数が過大なら、WINのproposal_fitと、該当するDELIVER項目へ反映し、reasonに「需要はあるが採算性に懸念」と明記する。

# 出力ルール

実行時に提示されるJSON schemaへ厳密に従う。

* need / win / deliver：上記15項目の0〜10の整数
* scope_hypothesis：想定用途・尺・撮影範囲を1文、300文字以内
* evidence_coverage：need / win / deliverごとにcoverageと400文字以内のreason
* reason：NEED / WIN / DELIVER、証拠と不確実性、採算性を600文字以内で要約
* strongest_signals：確認済みの強い根拠を最大3件
* risks：未確認と確認済みの逆風を区別し、最大3件
* research_needed：順位を変え得る確認事項だけ最大2件

企業識別情報、総合点、schema外フィールドは出力しない。9〜10点は同じ発表の言い換えではない複数根拠を必要とする。新Purposeだけで表現不足や発注余地まで確認済みとしない。
